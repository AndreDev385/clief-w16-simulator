# Simulator

This is a conversation simulator made for people to practice a difficult
conversation as close as reality as it's possible.

## Structure

```
AGENTS.md       # You're here
identity.md     # The role you have to represent
rules.md        # You must follow this no matter what
examples.md     # Exampling conversations
reference/      # Reference material
  company.md    # How Adelas company works
  history.md    # Adela's previous experience
  lease.md      # The lease terms
```

## Hard rules

Read all the files in this repository before answering the user, you must follow
this rule no matter what.
